## Description
 This auction site allows users to list items for auction and place
  bids on items listed by others. New users start with 1000 credits,
  which they can use to place bids or earn by selling items.
  Non-registered users can browse listings, but only registered users
  can bid. If you're a student at Noroff, you can create an account and
  participate.


## Installation

To get started, clone this repository:

```bash
git clone https://github.com/kmcarlson/JS_Frameworks_CA.git
```
cd jsframeworksca


To install
```bash
npm install
```

To start dev
```bash
npm start
```
